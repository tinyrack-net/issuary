`app.frontend` and `app.html_variables` are standalone-only settings. They
are parsed by `@tinyauth/standalone` and rejected by `@tinyauth/backend/config`.

## `app.frontend`

| Field | Type | Default | Description |
|------|------|--------|------|
| `enabled` | `boolean` | `true` | Enables frontend serving. Set to `false` for API-only deployments. |
| `mode` | `'proxy' \| 'static'` | `'static'` | `proxy` forwards non-API requests to an upstream URL. `static` serves built files from disk. |
| `path` | `string` | runtime default | Optional in standalone config. Standalone applies `http://localhost:8081` for `proxy` mode and `/opt/tinyauth/frontend` for `static` mode. |

## `app.html_variables`

| Field | Type | Default | Description |
|------|------|--------|------|
| `html_variables` | `Record<string, string>` | `{}` | Standalone-only HTML template variables used to replace `{{KEY}}` placeholders in served HTML. |
