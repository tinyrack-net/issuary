The `app` section contains core application settings including server configuration, JWT settings, theming, and localization.

## Basic Settings

```yaml
app:
  name: Tinyrack Auth          # Application name displayed in UI
  host: http://localhost:8080  # Base URL of the application
  port: 8080                   # Server port
  cookie_secret: <min-16-chars> # Secret for session cookies (required)
```

### Required Fields

| Field | Type | Description |
|-------|------|-------------|
| `cookie_secret` | string | Secret key for encrypting session cookies. Must be at least 16 characters. |

### Optional Fields

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `name` | string | `Tinyrack Auth` | Application name shown in UI |
| `host` | string | `http://localhost:8080` | Base URL of the application |
| `port` | number | `8080` | Server port to listen on |

## JWT Settings

Configure JSON Web Token behavior:

```yaml
app:
  jwt_access_token_ttl: 3600      # Access token lifetime in seconds (1 hour)
  jwt_refresh_token_ttl: 2592000  # Refresh token lifetime in seconds (30 days)
  jwt_key_rotation_enabled: true  # Enable automatic key rotation
  jwt_key_rotation_days: 30       # Days between key rotations
  jwt_key_overlap_days: 7         # Days to keep previous keys valid
```

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `jwt_access_token_ttl` | number | `3600` | Access token TTL in seconds (min: 60) |
| `jwt_refresh_token_ttl` | number | `2592000` | Refresh token TTL in seconds (min: 3600) |
| `jwt_key_rotation_enabled` | boolean | `true` | Enable automatic RS256 key rotation |
| `jwt_key_rotation_days` | number | `30` | Days between key rotations (min: 1) |
| `jwt_key_overlap_days` | number | `7` | Days to keep previous keys valid (min: 1) |

## Localization

Configure multi-language support:

```yaml
app:
  supported_languages:
    - en
    - ko
    - ja
  default_language: auto    # 'auto' detects from browser, or specify 'en', 'ko', 'ja'
  fallback_language: en     # Language to use when translation is missing
```

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `supported_languages` | string[] | `['en']` | List of supported language codes |
| `default_language` | string | `auto` | Default language or 'auto' for browser detection |
| `fallback_language` | string | `en` | Fallback when translation is unavailable |

## Theming

Customize the appearance of authentication pages:

```yaml
app:
  light_theme: light        # DaisyUI theme for light mode
  dark_theme: dark          # DaisyUI theme for dark mode
  theme_mode: system        # 'light', 'dark', or 'system'
  background_url: https://example.com/bg.jpg  # Background image URL
  icon_url: https://example.com/logo.png      # Logo URL
```

## Custom UI Text

Override default login page text:

```yaml
app:
  title:
    en: Welcome to My App
    ko: 내 앱에 오신 것을 환영합니다
  subtitle:
    en: Sign in to continue
    ko: 계속하려면 로그인하세요
  signup_implicit_terms:
    en: By signing up, you agree to our Terms of Service
    ko: 가입하면 서비스 약관에 동의하게 됩니다
```

## Signup Restrictions

Control who can sign up:

```yaml
app:
  allowed_signup_emails:
    - "*"                     # Allow all emails
    - "*@company.com"         # Allow specific domain
    - "admin@example.com"     # Allow specific email
```

- Empty array `[]` disables signup entirely
- `"*"` allows all email addresses
- `"*@domain.com"` allows all emails from a domain
- Specific emails can be whitelisted individually

## Proxy Configuration

When running behind a reverse proxy:

```yaml
app:
  trust_proxy: true           # Trust all proxies
  # Or more specific:
  trust_proxy: "loopback"     # Trust loopback addresses
  trust_proxy:
    - "10.0.0.0/8"            # Trust specific CIDR ranges
  trust_proxy: 1              # Trust nth hop
```

| Value | Description |
|-------|-------------|
| `true` | Trust all proxies |
| `false` | Don't trust any proxy |
| IP/CIDR string | Trust specific addresses |
| Array of IPs | Trust multiple addresses |
| Number | Trust nth hop from front |

## Complete Example

```yaml
app:
  name: My Authentication Server
  host: https://auth.example.com
  port: 8080
  cookie_secret: !env COOKIE_SECRET
  
  # JWT
  jwt_access_token_ttl: 3600
  jwt_refresh_token_ttl: 2592000
  jwt_key_rotation_enabled: true
  jwt_key_rotation_days: 30
  
  # Localization
  supported_languages:
    - en
    - ko
    - ja
  default_language: auto
  fallback_language: en
  
  # Theming
  light_theme: corporate
  dark_theme: business
  theme_mode: system
  icon_url: https://example.com/logo.png
  background_url: https://example.com/bg.jpg
  
  # Custom text
  title:
    en: Welcome
    ko: 환영합니다
  
  # Signup
  allowed_signup_emails:
    - "*@example.com"
  
  # Proxy
  trust_proxy: true
```
