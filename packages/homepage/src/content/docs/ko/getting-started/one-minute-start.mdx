---
title: 1분 시작
description: 1분 안에 Tinyauth를 실행해 보세요
---

`Tinyauth`를 1분 만에 실행해 보세요! Docker만 있으면 아래 명령어 하나로 바로 시작할 수 있어요.

```bash
docker run \
  --rm \
  -p 8080:8080 \
  -e COOKIE_SECRET="$(openssl rand -hex 32)" \
  tinyrack/tinyauth
```

---

## 실행 확인

서버가 시작되면 브라우저에서 [http://localhost:8080](http://localhost:8080)에 접속해요. `tinyauth`의 로그인 페이지가 표시돼요.

---

## 첫 번째 사용자 등록

기본 설정에서는 비밀번호 인증이 활성화되어 있지만, 가입이 허용되어 있지 않아요. `config.yaml`을 사용하여 가입을 허용하거나, 사전 정의 사용자를 추가할 수 있어요.

### 방법 1: 가입 허용

`config.yaml` 파일을 만들어 모든 이메일의 가입을 허용해요.

```yaml
# config.yaml
app:
  cookie_secret: "$(openssl rand -hex 32)"
  allowed_signup_emails:
    - '*'
```

```bash
docker run \
  --rm \
  -p 8080:8080 \
  -v ./config.yaml:/opt/config.yaml \
  tinyrack/tinyauth
```

### 방법 2: 사전 정의 사용자

`config.yaml`에서 직접 사용자를 정의할 수도 있어요.

```yaml
# config.yaml
app:
  cookie_secret: "$(openssl rand -hex 32)"

users:
  - id: admin
    email: admin@example.com
    password: your-password
    role: admin
```

```bash
docker run \
  --rm \
  -p 8080:8080 \
  -v ./config.yaml:/opt/config.yaml \
  tinyrack/tinyauth
```
