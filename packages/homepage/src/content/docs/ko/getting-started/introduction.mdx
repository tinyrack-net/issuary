Tinyauth는 OAuth2 및 OIDC 인증 서비스를 제공하는 경량 **OpenID Connect (OIDC) 프로바이더** 구현체입니다. 클라이언트 애플리케이션이 표준 OIDC 플로우를 통해 사용자를 인증하고 신원 정보를 얻을 수 있도록 하는 아이덴티티 프로바이더(IdP) 역할을 합니다.

## OIDC 프로바이더란?

OpenID Connect 프로바이더(아이덴티티 프로바이더 또는 IdP라고도 함)는 사용자를 인증하고 클라이언트 애플리케이션에 신원 정보를 제공하는 서비스입니다. "Google로 로그인" 또는 "GitHub로 로그인" 버튼을 보셨다면, 이러한 서비스들이 OIDC 프로바이더로 작동하는 것입니다.

Tinyauth를 사용하면 자체 OIDC 프로바이더를 운영하여 표준 프로토콜과의 호환성을 유지하면서 사용자 인증을 완전히 제어할 수 있습니다.

## 주요 기능

### 인증 방식

- **비밀번호 기반 인증** - 선택적 이메일 인증이 포함된 전통적인 이메일/비밀번호 로그인
- **WebAuthn/패스키** - 생체 인식 또는 보안 키를 사용한 최신 비밀번호 없는 인증
- **TOTP 2FA** - 추가 보안을 위한 시간 기반 일회용 비밀번호
- **소셜 로그인** - Google, GitHub, Apple과의 OAuth 연동

### OAuth2/OIDC 지원

- PKCE를 지원하는 Authorization Code Flow
- 토큰 발급 (ID 토큰, 액세스 토큰, 리프레시 토큰)
- 토큰 인트로스펙션 및 폐기
- 키 검색을 위한 JWKS 엔드포인트
- UserInfo 엔드포인트

### 개발자 경험

- YAML 파일을 통한 설정
- 환경 변수 보간
- 테스트를 위한 인메모리 데이터베이스
- Swagger/Scalar를 통한 포괄적인 API 문서

## 아키텍처

Tinyauth는 다음 패키지를 포함한 모노레포로 구축되었습니다:

| 패키지 | 설명 |
|--------|------|
| `@tinyauth/backend` | Fastify 기반 OAuth2/OIDC 인증 서버 |
| `@tinyauth/frontend` | TanStack Router와 DaisyUI를 사용한 React 프론트엔드 |
| `@tinyauth/homepage` | 문서 사이트 (현재 보고 계신 페이지) |
