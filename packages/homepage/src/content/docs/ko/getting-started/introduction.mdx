`Tinyauth`는 **사용자**를 위한 오픈소스 인증 제공자(OIDC Provider) 소프트웨어에요. 사용자 경험을 중심으로 설계되어 빠르고 편리한 로그인 과정을 제공하는 것을 목표로 가지고 있어요.

또한 `Tinyauth`는 경량, 오픈소스, 선언적, 단순성도 핵심 가치로 삼고 있어요. 복잡한 설정 없이도 몇 분 만에 완전한 기능을 갖춘 인증 서버를 구축할 수 있으면서, 추후 필요에 따라 수평적으로도 확장할 수 있도록 설계됐어요.

Tinyauth를 사용하면 복잡한 인증 시스템을 직접 구축하는 대신, 단일 YAML 파일만으로 완전한 기능을 갖춘 인증 서버를 운영할 수 있어요.

```yaml
app:
  cookie_secret: your_cookie_secret_here
```

## 주요 특징

### 표준 프로토콜 지원

- **OAuth 2.0 / OIDC 완전 호환** - Authorization Code Flow with PKCE 지원
- **표준 엔드포인트** - authorize, token, userinfo, introspect, revoke
- **JWKS 자동 관리** - RS256 비대칭 키 자동 생성 및 로테이션

### 다양한 인증 방법

- **비밀번호 인증** - 이메일 인증, 비밀번호 재설정 지원
- **패스키(WebAuthn)** - 생체 인식, 보안 키를 활용한 비밀번호 없는 로그인
- **소셜 로그인** - GitHub, Google, Apple 및 Generic OAuth 지원
- **2단계 인증(2FA)** - TOTP(인증 앱) 및 패스키 2FA 지원

### 간편한 설정과 배포

- **Configuration-as-Code** - 단일 `config.yaml` 파일로 모든 설정 관리
- **선언적 사용자/클라이언트 관리** - 설정 파일에서 직접 정의 가능
- **Docker 지원** - 단일 컨테이너로 즉시 배포
- **데이터베이스 유연성** - PostgreSQL, SQLite 지원

### 커스터마이징

- **UI 테마** - 35개 이상의 DaisyUI 테마 지원
- **브랜딩** - 로고, 배경 이미지, 제목/부제목 커스터마이징
- **다국어 지원** - 한국어, 영어, 일본어
- **약관 관리** - 이용약관, 개인정보처리방침 설정

## 언제 Tinyauth를 사용하나요?

Tinyauth는 다음과 같은 상황에 적합해요:

- **자체 인증 서버가 필요할 때** - SaaS 서비스나 사내 시스템에 표준 기반 인증이 필요한 경우
- **셀프호스팅을 원할 때** - 데이터 주권이 중요하거나 클라우드 종속성을 피하고 싶은 경우
- **빠른 설정이 필요할 때** - YAML 설정 파일 하나로 몇 분 안에 인증 서버를 구축하고 싶은 경우
- **표준 프로토콜이 필요할 때** - OAuth 2.0/OIDC 호환 클라이언트와 통합해야 하는 경우
