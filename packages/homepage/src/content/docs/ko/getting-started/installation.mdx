이 가이드는 개발 또는 프로덕션 용도로 Tinyrack Auth를 설정하는 방법을 안내합니다.

## 사전 요구 사항

시작하기 전에 다음이 설치되어 있는지 확인하세요:

- **Node.js** 20.x 이상
- **pnpm** 9.x 이상 (권장 패키지 매니저)
- **Git** (저장소 복제용)

## 빠른 시작

### 1. 저장소 복제

```bash
git clone https://github.com/tinyrack/auth.git
cd auth
```

### 2. 의존성 설치

```bash
pnpm install
```

### 3. 애플리케이션 설정

`packages/backend/config.yaml` 파일을 생성합니다:

```yaml
app:
  host: 0.0.0.0
  port: 8080
  base_url: http://localhost:8080
  jwt_key_rotation_enabled: true
  jwt_key_rotation_days: 30

database:
  type: sqlite
  path: ./data/auth.db

smtp:
  host: smtp.example.com
  port: 587
  user: your-email@example.com
  password: !env SMTP_PASSWORD

basic_authentication_methods:
  password:
    enabled: true
    email_verification: false
    totp:
      enabled: true
  passkey:
    enabled: true

users:
  - id: admin-user-id
    email: admin@example.com
    password: !env ADMIN_PASSWORD
```

### 4. 개발 서버 시작

```bash
pnpm dev
```

다음이 시작됩니다:
- 백엔드 서버: `http://localhost:8080`
- 프론트엔드 개발 서버: `http://localhost:8081`

## 환경 변수

루트 디렉토리에 `.env` 파일을 생성합니다:

```bash
# 이메일 전송을 위한 SMTP 비밀번호
SMTP_PASSWORD=your-smtp-password

# 관리자 사용자 비밀번호
ADMIN_PASSWORD=your-secure-admin-password
```

## 데이터베이스 옵션

Tinyrack Auth는 여러 데이터베이스 백엔드를 지원합니다:

### SQLite (기본값)

```yaml
database:
  type: sqlite
  path: ./data/auth.db
```

### PostgreSQL

```yaml
database:
  type: postgres
  host: localhost
  port: 5432
  user: postgres
  password: !env DB_PASSWORD
  database: tinyrack_auth
```

### 인메모리 (테스트용)

```yaml
database:
  type: memory
```

## 프로덕션 빌드

```bash
# 모든 패키지 빌드
pnpm build

# 프로덕션 서버 시작
cd packages/backend
pnpm serve
```
