---
title: 이용약관
description: 이용약관 및 동의 관리 구성하기
---

Tinyrack Auth는 등록 시 사용자가 동의해야 하는 설정 가능한 이용약관을 지원합니다. 약관은 필수 또는 선택으로 설정할 수 있으며, 명시적 또는 암시적 동의 모드를 사용할 수 있습니다.

## 설정

약관은 `terms` 섹션에서 설정합니다:

```yaml
terms:
  - id: privacy-policy
    required: true
    consent_mode: explicit
    version: "1.0.0"
    content:
      en:
        title: Privacy Policy
        type: link
        content: https://example.com/privacy
      ko:
        title: 개인정보처리방침
        type: link
        content: https://example.com/ko/privacy

  - id: terms-of-service
    required: true
    consent_mode: explicit
    version: "1.0.0"
    content:
      en:
        title: Terms of Service
        type: text
        content: |
          서비스를 이용함으로써 귀하는 동의합니다...
```

## 약관 설정

| 필드 | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `id` | string | - | 고유 식별자 (소문자, 영숫자, `-`, `_`) |
| `required` | boolean | `true` | 동의가 필수인지 여부 |
| `consent_mode` | string | `explicit` | `explicit` 또는 `implicit` |
| `version` | string | - | 변경 추적을 위한 버전 문자열 |
| `content` | object | - | 언어 코드별 다국어 콘텐츠 |

## 콘텐츠 타입

### 링크 콘텐츠

외부 문서로 연결:

```yaml
content:
  ko:
    title: 개인정보처리방침
    type: link
    content: https://example.com/ko/privacy
```

### 텍스트 콘텐츠

인라인 텍스트 콘텐츠:

```yaml
content:
  ko:
    title: 서비스 이용약관
    type: text
    content: |
      1. 약관의 수락
      서비스에 접근하거나 사용함으로써...
      
      2. 사용자 책임
      귀하는 다음에 동의합니다...
```

## 동의 모드

### 명시적 동의

사용자가 동의하려면 체크박스를 적극적으로 선택해야 합니다:

```yaml
terms:
  - id: marketing
    required: false
    consent_mode: explicit
    version: "1.0.0"
    content:
      ko:
        title: 마케팅 수신 동의
        type: text
        content: 마케팅 이메일 수신에 동의합니다
```

UI에서 사용자가 선택해야 하는 체크박스로 표시됩니다.

### 암시적 동의

가입이 동의를 의미합니다 (체크박스 표시 안 됨):

```yaml
terms:
  - id: privacy-policy
    required: true
    consent_mode: implicit
    version: "1.0.0"
    content:
      ko:
        title: 개인정보처리방침
        type: link
        content: https://example.com/ko/privacy
```

암시적 동의 약관의 경우 알림 메시지를 구성합니다:

```yaml
app:
  signup_implicit_terms:
    en: By signing up, you agree to our Privacy Policy and Terms of Service
    ko: 가입하면 개인정보처리방침 및 서비스 약관에 동의하게 됩니다
```

## 버전 추적

약관이 업데이트되면 버전을 증가시킵니다:

```yaml
terms:
  - id: privacy-policy
    version: "2.0.0"  # 1.0.0에서 업데이트
```

이전 버전에 동의한 사용자는 새 버전에 동의하라는 프롬프트를 받을 수 있습니다.

## 다국어 지원

여러 언어로 콘텐츠를 제공합니다:

```yaml
terms:
  - id: privacy-policy
    required: true
    consent_mode: explicit
    version: "1.0.0"
    content:
      en:
        title: Privacy Policy
        type: link
        content: https://example.com/privacy
      ko:
        title: 개인정보처리방침
        type: link
        content: https://example.com/ko/privacy
      ja:
        title: プライバシーポリシー
        type: link
        content: https://example.com/ja/privacy
```

UI는 사용자의 선호 언어로 콘텐츠를 자동으로 표시합니다.

## API 엔드포인트

### 약관 조회

```http
GET /api/v1/terms
```

현재 사용자에게 동의가 필요한 모든 약관을 반환합니다.

### 동의 제출

```http
POST /api/v1/terms/consent
Content-Type: application/json

{
  "consents": [
    {
      "termId": "privacy-policy",
      "version": "1.0.0",
      "agreed": true
    },
    {
      "termId": "marketing",
      "version": "1.0.0",
      "agreed": false
    }
  ]
}
```

## 전체 예제

```yaml
app:
  signup_implicit_terms:
    en: By signing up, you agree to our Privacy Policy
    ko: 가입하면 개인정보처리방침에 동의하게 됩니다

terms:
  # 개인정보처리방침 - 필수, 암시적
  - id: privacy-policy
    required: true
    consent_mode: implicit
    version: "1.0.0"
    content:
      en:
        title: Privacy Policy
        type: link
        content: https://example.com/privacy
      ko:
        title: 개인정보처리방침
        type: link
        content: https://example.com/ko/privacy

  # 서비스 이용약관 - 필수, 명시적
  - id: terms-of-service
    required: true
    consent_mode: explicit
    version: "1.0.0"
    content:
      en:
        title: Terms of Service
        type: link
        content: https://example.com/terms
      ko:
        title: 서비스 이용약관
        type: link
        content: https://example.com/ko/terms

  # 마케팅 - 선택, 명시적
  - id: marketing
    required: false
    consent_mode: explicit
    version: "1.0.0"
    content:
      en:
        title: Marketing Communications
        type: text
        content: I agree to receive promotional emails and updates
      ko:
        title: 마케팅 수신 동의
        type: text
        content: 프로모션 이메일 및 업데이트 수신에 동의합니다
```

## 약관이 포함된 등록 흐름

```
사용자가 등록 양식 작성
           │
           ▼
약관 표시 ──► 필수: 반드시 동의
           │    선택: 건너뛸 수 있음
           ▼
사용자가 동의 제출
           │
           ▼
버전과 함께 동의 기록
           │
           ▼
등록 완료
```

## 모범 사례

1. **ID를 안정적으로 유지** - 사용자가 동의한 후 약관 ID를 변경하지 않음
2. **약관 버전 관리** - 규정 준수를 위해 변경 사항 추적
3. **긴 문서에는 링크 사용** - 가입 흐름을 깔끔하게 유지
4. **번역 제공** - 모든 사용자 언어 지원
5. **필수 vs 선택** - 정말 필요한 약관만 필수로 설정
6. **표준 약관에는 암시적** - 개인정보처리방침은 암시적일 수 있음
7. **마케팅에는 명시적** - 마케팅 동의는 명시적이어야 함
