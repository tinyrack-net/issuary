이 문서는 `tinyauth`의 `config.yaml` 설정 파일에서 사용 가능한 모든 항목, 유형, 기본값 및 관련 환경 변수를 정리한 전체 레퍼런스예요.

---

## `app` - 애플리케이션 설정

### 서버

| 항목 | 유형 | 기본값 | 환경 변수 | 설명 |
|------|------|--------|-----------|------|
| `host` | `string` | `http://localhost:8080` | `APP_HOST` | 서비스의 공개 URL |
| `port` | `number` (1-65535) | `8080` | `PORT` | 서버 리스닝 포트 |
| `cookie_secret` | `string` (16자 이상) | **필수** | `COOKIE_SECRET` | 세션 쿠키 서명 키 |
| `trust_proxy` | `boolean \| string \| string[] \| number` | `false` | `TRUST_PROXY` | 리버스 프록시 신뢰 설정 |

### JWT / 토큰

| 항목 | 유형 | 기본값 | 환경 변수 | 설명 |
|------|------|--------|-----------|------|
| `jwt_access_token_ttl` | `integer` (최소 60) | `3600` | `JWT_ACCESS_TOKEN_TTL` | 액세스 토큰 수명 (초) |
| `jwt_refresh_token_ttl` | `integer` (최소 3600) | `2592000` | `JWT_REFRESH_TOKEN_TTL` | 리프레시 토큰 수명 (초) |
| `jwt_key_rotation_enabled` | `boolean` | `true` | `JWT_KEY_ROTATION_ENABLED` | JWT 키 자동 순환 활성화 |
| `jwt_key_rotation_days` | `integer` (최소 1) | `30` | `JWT_KEY_ROTATION_DAYS` | 키 순환 주기 (일) |
| `jwt_key_overlap_days` | `integer` (최소 1) | `7` | `JWT_KEY_OVERLAP_DAYS` | 이전 키 유효 유지 기간 (일) |

### 회원가입 / 접근 제어

| 항목 | 유형 | 기본값 | 환경 변수 | 설명 |
|------|------|--------|-----------|------|
| `allowed_signup_emails` | `string[]` | `[]` | - | 가입 허용 이메일 패턴 (`*`, `*@domain.com` 등) |
| `account_deletion` | `boolean` | `false` | `ACCOUNT_DELETION` | 사용자 계정 삭제 기능 활성화 |

### 다국어 (i18n)

| 항목 | 유형 | 기본값 | 환경 변수 | 설명 |
|------|------|--------|-----------|------|
| `supported_languages` | `Locale[]` | `['en']` | - | 지원 언어 (`en`, `ko`, `ja`) |
| `default_language` | `'auto' \| Locale` | `'auto'` | `DEFAULT_LANGUAGE` | 기본 언어 |
| `fallback_language` | `Locale` | `'en'` | `FALLBACK_LANGUAGE` | 대체 언어 |

### UI / 테마 / 브랜딩

| 항목 | 유형 | 기본값 | 환경 변수 | 설명 |
|------|------|--------|-----------|------|
| `theme_mode` | `'light' \| 'dark' \| 'system'` | `'system'` | `THEME_MODE` | 테마 모드 |
| `light_theme` | `AppTheme` | `'light'` | `LIGHT_THEME` | 라이트 모드 테마 |
| `dark_theme` | `AppTheme` | `'dark'` | `DARK_THEME` | 다크 모드 테마 |
| `background_url` | `string` (URL) | - | - | 배경 이미지 URL |
| `icon_url` | `string` (URL) | - | - | 로고 이미지 URL |
| `title` | `Record<string, string>` | - | - | 다국어 제목 |
| `subtitle` | `Record<string, string>` | - | - | 다국어 부제목 |
| `signup_implicit_terms` | `Record<string, string>` | - | - | 암시적 동의 안내 문구 (HTML) |

## `database` - 데이터베이스 설정

`type` 필드에 따라 설정 항목이 달라요.

### SQLite (`type: 'sqlite'`)

| 항목 | 유형 | 기본값 | 환경 변수 | 설명 |
|------|------|--------|-----------|------|
| `type` | `'sqlite'` | - | `DB_TYPE` | 데이터베이스 유형 |
| `path` | `string` | `/opt/tinyauth/database.db` | `DB_PATH` | 데이터베이스 파일 경로 |

### PostgreSQL (`type: 'postgres'`)

| 항목 | 유형 | 기본값 | 환경 변수 | 설명 |
|------|------|--------|-----------|------|
| `type` | `'postgres'` | - | `DB_TYPE` | 데이터베이스 유형 |
| `host` | `string` | `'localhost'` | `DATABASE_HOST` | 호스트 |
| `port` | `number` | `5432` | `DATABASE_PORT` | 포트 |
| `name` | `string` | `'test'` | `DATABASE_NAME` | 데이터베이스 이름 |
| `user` | `string` | `'test'` | `DATABASE_USER` | 사용자 |
| `password` | `string` | `'test'` | `DATABASE_PASSWORD` | 비밀번호 |

## `auth` - 인증 설정

### 비밀번호 (`auth.password`)

| 항목 | 유형 | 기본값 | 설명 |
|------|------|--------|------|
| `enabled` | `boolean` | `true` | 비밀번호 인증 활성화 |
| `email_verification` | `boolean` | `true` | 이메일 인증 필수 여부 |
| `second_factor.required` | `boolean` | `false` | 2단계 인증 필수 여부 |
| `totp.enabled` | `boolean` | `false` | TOTP 활성화 |
| `totp.issuer` | `string` | `'Tinyrack'` | 인증 앱 표시 이름 |

### 패스키 (`auth.passkey`)

| 항목 | 유형 | 기본값 | 설명 |
|------|------|--------|------|
| `enabled` | `boolean` | `false` | 패스키 인증 활성화 |
| `email_verification` | `boolean` | `true` | 이메일 인증 필수 여부 |
| `rp_id` | `string` | `app.host`에서 추출 | Relying Party ID (도메인만) |
| `origins` | `string[]` | `[app.host]` | 허용 WebAuthn 출처 |

## `identity_providers` - 타사 로그인 설정

배열 형태로 여러 제공자를 설정할 수 있어요. 자세한 내용은 [타사 로그인 개요](/ko/configuration/oauth/overview)를 참고해 주세요.

### 공통 항목

| 항목 | 유형 | 기본값 | 설명 |
|------|------|--------|------|
| `id` | `string` | - | 고유 식별자 |
| `type` | `'github' \| 'google' \| 'apple' \| 'generic_oauth'` | - | 제공자 유형 |
| `enabled` | `boolean` | `false` | 활성화 여부 |
| `display_name` | `string` | - | 표시 이름 (`generic_oauth`에서 필수) |
| `icon_url` | `string` | - | 아이콘 URL |
| `client_id` | `string` | - | OAuth 클라이언트 ID |
| `client_secret` | `string` | - | OAuth 클라이언트 시크릿 |
| `scopes` | `string[]` | 유형별 기본값 | OAuth 스코프 |
| `email_conflict_strategy` | `'auto_link' \| 'require_link'` | `'auto_link'` | 이메일 충돌 처리 방식 |

## `clients` - OAuth 클라이언트 설정

배열 형태로 여러 클라이언트를 설정할 수 있어요. 자세한 내용은 [클라이언트 연동](/ko/configuration/client-integration/overview)을 참고해 주세요.

| 항목 | 유형 | 설명 |
|------|------|------|
| `id` | `string` | 내부 고유 식별자 |
| `name` | `string` | 표시 이름 |
| `logo_uri` | `string` | 로고 URL |
| `client_id` | `string` | 공개 클라이언트 ID |
| `client_secret` | `string` | 클라이언트 시크릿 (공개 클라이언트는 생략) |
| `redirect_uris` | `string[]` | 허용 리다이렉트 URL |
| `response_types` | `string[]` | 허용 응답 유형 |
| `grant_types` | `string[]` | 허용 권한 부여 유형 |
| `scope` | `string` | 허용 스코프 (공백 구분) |

## `terms` - 이용약관 설정

배열 형태로 여러 약관을 설정할 수 있어요. 자세한 내용은 [암시적 플로우](/ko/configuration/terms/implicit-flow) 및 [명시적 플로우](/ko/configuration/terms/explicit-flow)를 참고해 주세요.

| 항목 | 유형 | 기본값 | 설명 |
|------|------|--------|------|
| `id` | `string` | - | 고유 식별자 (소문자, `-`, `_`) |
| `required` | `boolean` | `true` | 동의 필수 여부 |
| `consent_mode` | `'explicit' \| 'implicit'` | `'explicit'` | 동의 수집 방식 |
| `version` | `string` | - | 버전 문자열 |
| `content` | `Record<lang, {title, type, content}>` | - | 언어별 약관 내용 |

## `cleanup` - 데이터 정리 설정

자세한 내용은 [작업 스케줄러](/ko/configuration/scheduler)를 참고해 주세요.

| 항목 | 유형 | 기본값 | 설명 |
|------|------|--------|------|
| `revoked_tokens.enabled` | `boolean` | `true` | 취소된 토큰 정리 |
| `revoked_tokens.retention` | `DurationString` | `'0'` | 보존 기간 |
| `oauth_codes.enabled` | `boolean` | `true` | 인증 코드 정리 |
| `oauth_codes.consumed_retention` | `DurationString` | `'24h'` | 사용된 코드 보존 기간 |
| `email_verifications.enabled` | `boolean` | `true` | 이메일 인증 토큰 정리 |
| `email_verifications.retention` | `DurationString` | `'0'` | 보존 기간 |
| `password_resets.enabled` | `boolean` | `true` | 비밀번호 재설정 토큰 정리 |
| `password_resets.retention` | `DurationString` | `'0'` | 보존 기간 |
| `deleted_users.enabled` | `boolean` | `true` | 삭제된 사용자 영구 삭제 |
| `deleted_users.retention` | `DurationString` | `'30d'` | 유예 기간 |
| `jwt_keys.enabled` | `boolean` | `true` | JWT 키 순환 |

:::note
`DurationString` 형식: `"0"` (즉시), `"30s"` (초), `"30m"` (분), `"24h"` (시간), `"7d"` (일), `"1y"` (년)
:::
