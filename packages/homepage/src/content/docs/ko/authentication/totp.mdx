TOTP(시간 기반 일회용 비밀번호)는 로그인 시 인증 앱에서 시간에 민감한 코드를 요구하여 추가 보안 계층을 제공합니다.

## TOTP란?

TOTP는 30초마다 변경되는 6자리 코드를 생성합니다. 사용자는 다음과 같이 TOTP를 설정합니다:

1. 인증 앱으로 QR 코드 스캔
2. 생성된 코드를 입력하여 설정 확인
3. 향후 로그인 시 앱에서 코드 사용

## 설정

```yaml
basic_authentication_methods:
  password:
    enabled: true
    second_factor:
      required: false
    totp:
      enabled: true
      issuer: My App
```

## 옵션

| 필드 | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `totp.enabled` | boolean | `false` | TOTP를 2FA 옵션으로 활성화 |
| `totp.issuer` | string | `Tinyrack` | 인증 앱에 표시되는 발급자 이름 |
| `second_factor.required` | boolean | `false` | 등록 후 2FA 설정 필요 |

## 발급자 설정

`issuer`는 인증 앱에 표시되어 사용자가 계정을 식별하는 데 도움이 됩니다:

```yaml
totp:
  enabled: true
  issuer: Acme Corp
```

인증 앱에서 계정이 다음과 같이 표시됩니다:
```
Acme Corp
user@example.com
```

## 설정 흐름

1. 사용자가 보안 설정으로 이동
2. TOTP 설정 시작
3. 인증 앱으로 QR 코드 스캔
4. 확인 코드 입력
5. 계정에 TOTP 활성화

```
사용자가 설정 시작
        │
        ▼
서버가 시크릿 생성
        │
        ▼
QR 코드 표시 ──► 사용자가 앱으로 스캔
        │
        ▼
사용자가 코드 입력
        │
        ▼
서버가 코드 검증
        │
        ▼
TOTP 활성화 + 복구 코드 제공
```

## 로그인 흐름

TOTP가 활성화된 사용자가 로그인할 때:

1. 사용자가 이메일과 비밀번호 입력
2. 비밀번호 검증
3. TOTP 코드 입력 프롬프트
4. 인증 앱에서 코드 입력
5. 코드 검증, 로그인 완료

```
이메일 + 비밀번호
       │
       ▼
비밀번호 검증됨
       │
       ▼
TOTP 코드 필요 ──► 사용자가 코드 입력
       │
       ▼
코드 검증됨
       │
       ▼
로그인 완료
```

## API 엔드포인트

### TOTP 설정 초기화

```http
POST /api/v1/user/totp/setup
```

응답:
```json
{
  "secret": "JBSWY3DPEHPK3PXP",
  "qrCode": "data:image/png;base64,...",
  "uri": "otpauth://totp/My%20App:user@example.com?secret=JBSWY3DPEHPK3PXP&issuer=My%20App"
}
```

### TOTP 확인 및 활성화

```http
POST /api/v1/user/totp/confirm
Content-Type: application/json

{
  "code": "123456"
}
```

응답에 복구 코드 포함:
```json
{
  "recoveryCodes": [
    "ABCD-1234-EFGH",
    "IJKL-5678-MNOP",
    ...
  ]
}
```

### 로그인 시 TOTP 검증

```http
POST /api/v1/auth/totp/verify
Content-Type: application/json

{
  "code": "123456"
}
```

### TOTP 비활성화

```http
DELETE /api/v1/user/totp
Content-Type: application/json

{
  "code": "123456"
}
```

## 복구 코드

TOTP가 활성화되면 긴급 접근을 위한 복구 코드가 제공됩니다:

- 10개의 일회용 코드
- 각 코드는 한 번만 사용 가능
- 오프라인에서 안전하게 보관

### 복구 코드 사용

```http
POST /api/v1/auth/totp/recovery/verify
Content-Type: application/json

{
  "code": "ABCD-1234-EFGH"
}
```

## 2FA 필수화

모든 사용자가 2FA를 설정하도록 강제:

```yaml
basic_authentication_methods:
  password:
    enabled: true
    second_factor:
      required: true
    totp:
      enabled: true
```

`second_factor.required`가 `true`일 때:

1. 신규 사용자는 등록 후 2FA를 설정해야 함
2. 2FA가 설정될 때까지 애플리케이션에 접근 불가
3. 2FA가 없는 기존 사용자는 설정 프롬프트를 받음

## 호환 인증 앱

TOTP는 모든 표준 인증 앱과 호환됩니다:

- Google Authenticator (iOS, Android)
- Microsoft Authenticator (iOS, Android)
- Authy (iOS, Android, 데스크톱)
- 1Password (iOS, Android, 데스크톱)
- Bitwarden (iOS, Android, 데스크톱)

## 모범 사례

1. **2FA 채택 장려** - 보안 프롬프트 표시
2. **복구 코드 제공** - 사용자에게 백업 접근 필요
3. **여러 2FA 방법 허용** - TOTP + 패스키
4. **설명적인 발급자 이름 사용** - 사용자가 계정 식별에 도움
5. **속도 제한 구현** - 코드에 대한 무차별 대입 방지

## 문제 해결

### "유효하지 않은 코드" 오류

1. **시간 동기화**: 사용자의 기기 시간이 정확한지 확인
2. **코드 만료**: 코드는 30초 동안 유효
3. **잘못된 계정**: 사용자가 다른 계정의 코드를 사용 중일 수 있음

### QR 코드가 스캔되지 않음

1. 수동 입력 옵션 제공 (시크릿 키)
2. QR 코드가 스캔할 수 있을 만큼 큰지 확인
3. 화면 반사 또는 손상 확인

### 인증 앱 접근 상실

사용자는 복구 코드를 사용하여 접근을 되찾은 다음 새 기기에서 TOTP를 다시 설정할 수 있습니다.
