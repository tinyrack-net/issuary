이 가이드에서는 서버 측 인증을 사용하여 Next.js 애플리케이션과 Tinyrack Auth를 연동하는 방법을 보여줍니다.

## 개요

Next.js 애플리케이션에는 서버 측 토큰 처리를 권장합니다:

- 인증 코드는 서버에서 교환
- 토큰은 HTTP-only 쿠키에 저장
- 클라이언트 측 토큰 저장보다 더 나은 보안

## 설정

### 1. 의존성 설치

```bash
npm install jose
```

### 2. OAuth 클라이언트 구성

Tinyrack Auth `config.yaml`에서:

```yaml
providers:
  - id: nextjs-app
    name: My Next.js App
    client_id: nextjs-client-id
    client_secret: !env NEXTJS_CLIENT_SECRET
    redirect_uris:
      - http://localhost:3000/api/auth/callback
      - https://myapp.example.com/api/auth/callback
    response_types:
      - code
    grant_types:
      - authorization_code
      - refresh_token
    scope: openid profile email
```

### 3. 환경 변수

`.env.local` 생성:

```bash
AUTH_URL=http://localhost:8080
AUTH_CLIENT_ID=nextjs-client-id
AUTH_CLIENT_SECRET=your-client-secret
AUTH_REDIRECT_URI=http://localhost:3000/api/auth/callback
NEXTAUTH_SECRET=your-nextauth-secret
```

## 구현

### 로그인 라우트

`app/api/auth/login/route.ts` 생성:

```typescript
import { NextRequest, NextResponse } from 'next/server';
import crypto from 'crypto';

export async function GET(request: NextRequest) {
  // PKCE 값 생성
  const codeVerifier = crypto.randomBytes(32).toString('base64url');
  const codeChallenge = crypto
    .createHash('sha256')
    .update(codeVerifier)
    .digest('base64url');
  
  // CSRF 보호를 위한 state 생성
  const state = crypto.randomBytes(16).toString('hex');
  
  // 인증 URL 구성
  const authUrl = new URL(`${process.env.AUTH_URL}/application/oauth/authorize`);
  authUrl.searchParams.set('client_id', process.env.AUTH_CLIENT_ID!);
  authUrl.searchParams.set('redirect_uri', process.env.AUTH_REDIRECT_URI!);
  authUrl.searchParams.set('response_type', 'code');
  authUrl.searchParams.set('scope', 'openid profile email');
  authUrl.searchParams.set('state', state);
  authUrl.searchParams.set('code_challenge', codeChallenge);
  authUrl.searchParams.set('code_challenge_method', 'S256');
  
  // PKCE verifier와 state를 쿠키에 저장
  const response = NextResponse.redirect(authUrl.toString());
  response.cookies.set('code_verifier', codeVerifier, {
    httpOnly: true,
    secure: process.env.NODE_ENV === 'production',
    sameSite: 'lax',
    maxAge: 600, // 10분
  });
  response.cookies.set('oauth_state', state, {
    httpOnly: true,
    secure: process.env.NODE_ENV === 'production',
    sameSite: 'lax',
    maxAge: 600,
  });
  
  return response;
}
```

### 콜백 라우트

`app/api/auth/callback/route.ts` 생성:

```typescript
import { NextRequest, NextResponse } from 'next/server';

export async function GET(request: NextRequest) {
  const searchParams = request.nextUrl.searchParams;
  const code = searchParams.get('code');
  const state = searchParams.get('state');
  const error = searchParams.get('error');
  
  // 오류 처리
  if (error) {
    return NextResponse.redirect(
      new URL(`/login?error=${error}`, request.url)
    );
  }
  
  // state 검증
  const storedState = request.cookies.get('oauth_state')?.value;
  if (state !== storedState) {
    return NextResponse.redirect(
      new URL('/login?error=invalid_state', request.url)
    );
  }
  
  // code verifier 가져오기
  const codeVerifier = request.cookies.get('code_verifier')?.value;
  if (!codeVerifier) {
    return NextResponse.redirect(
      new URL('/login?error=missing_verifier', request.url)
    );
  }
  
  // 코드를 토큰으로 교환
  const tokenResponse = await fetch(
    `${process.env.AUTH_URL}/application/oauth/token`,
    {
      method: 'POST',
      headers: {
        'Content-Type': 'application/x-www-form-urlencoded',
      },
      body: new URLSearchParams({
        grant_type: 'authorization_code',
        code: code!,
        redirect_uri: process.env.AUTH_REDIRECT_URI!,
        client_id: process.env.AUTH_CLIENT_ID!,
        client_secret: process.env.AUTH_CLIENT_SECRET!,
        code_verifier: codeVerifier,
      }),
    }
  );
  
  if (!tokenResponse.ok) {
    return NextResponse.redirect(
      new URL('/login?error=token_exchange_failed', request.url)
    );
  }
  
  const tokens = await tokenResponse.json();
  
  // 토큰을 쿠키에 저장
  const response = NextResponse.redirect(new URL('/dashboard', request.url));
  
  response.cookies.set('access_token', tokens.access_token, {
    httpOnly: true,
    secure: process.env.NODE_ENV === 'production',
    sameSite: 'lax',
    maxAge: tokens.expires_in,
  });
  
  response.cookies.set('refresh_token', tokens.refresh_token, {
    httpOnly: true,
    secure: process.env.NODE_ENV === 'production',
    sameSite: 'lax',
    maxAge: 30 * 24 * 60 * 60, // 30일
  });
  
  // 임시 쿠키 삭제
  response.cookies.delete('code_verifier');
  response.cookies.delete('oauth_state');
  
  return response;
}
```

### 로그아웃 라우트

`app/api/auth/logout/route.ts` 생성:

```typescript
import { NextRequest, NextResponse } from 'next/server';

export async function GET(request: NextRequest) {
  const refreshToken = request.cookies.get('refresh_token')?.value;
  
  // 인증 서버에서 토큰 폐기
  if (refreshToken) {
    await fetch(`${process.env.AUTH_URL}/application/oauth/revoke`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/x-www-form-urlencoded',
      },
      body: new URLSearchParams({
        token: refreshToken,
        token_type_hint: 'refresh_token',
      }),
    });
  }
  
  // 쿠키 삭제 및 리디렉션
  const response = NextResponse.redirect(new URL('/', request.url));
  response.cookies.delete('access_token');
  response.cookies.delete('refresh_token');
  
  return response;
}
```

### 사용자 세션 헬퍼

`lib/auth.ts` 생성:

```typescript
import { cookies } from 'next/headers';
import { createRemoteJWKSet, jwtVerify } from 'jose';

const JWKS = createRemoteJWKSet(
  new URL(`${process.env.AUTH_URL}/.well-known/jwks.json`)
);

export interface User {
  sub: string;
  email: string;
  name?: string;
}

export async function getUser(): Promise<User | null> {
  const cookieStore = cookies();
  const accessToken = cookieStore.get('access_token')?.value;
  
  if (!accessToken) {
    return null;
  }
  
  try {
    const { payload } = await jwtVerify(accessToken, JWKS, {
      issuer: process.env.AUTH_URL,
      audience: process.env.AUTH_CLIENT_ID,
    });
    
    return {
      sub: payload.sub as string,
      email: payload.email as string,
      name: payload.name as string | undefined,
    };
  } catch {
    return null;
  }
}
```

### 보호된 페이지

`app/dashboard/page.tsx` 생성:

```typescript
import { redirect } from 'next/navigation';
import { getUser } from '@/lib/auth';

export default async function DashboardPage() {
  const user = await getUser();
  
  if (!user) {
    redirect('/api/auth/login');
  }
  
  return (
    <div>
      <h1>대시보드</h1>
      <p>환영합니다, {user.name || user.email}!</p>
      <a href="/api/auth/logout">로그아웃</a>
    </div>
  );
}
```

### 미들웨어 (선택)

라우트 보호를 위한 `middleware.ts` 생성:

```typescript
import { NextResponse } from 'next/server';
import type { NextRequest } from 'next/server';

const protectedRoutes = ['/dashboard', '/settings', '/profile'];

export function middleware(request: NextRequest) {
  const accessToken = request.cookies.get('access_token');
  const isProtectedRoute = protectedRoutes.some(route =>
    request.nextUrl.pathname.startsWith(route)
  );
  
  if (isProtectedRoute && !accessToken) {
    return NextResponse.redirect(new URL('/api/auth/login', request.url));
  }
  
  return NextResponse.next();
}

export const config = {
  matcher: ['/dashboard/:path*', '/settings/:path*', '/profile/:path*'],
};
```

## NextAuth.js 사용

대안으로 커스텀 프로바이더와 함께 NextAuth.js를 사용할 수 있습니다:

```typescript
// app/api/auth/[...nextauth]/route.ts
import NextAuth from 'next-auth';

const handler = NextAuth({
  providers: [
    {
      id: 'tinyrack',
      name: 'Tinyrack Auth',
      type: 'oauth',
      wellKnown: `${process.env.AUTH_URL}/.well-known/openid-configuration`,
      clientId: process.env.AUTH_CLIENT_ID,
      clientSecret: process.env.AUTH_CLIENT_SECRET,
      authorization: { params: { scope: 'openid profile email' } },
      idToken: true,
      profile(profile) {
        return {
          id: profile.sub,
          email: profile.email,
          name: profile.name,
        };
      },
    },
  ],
});

export { handler as GET, handler as POST };
```
