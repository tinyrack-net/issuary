`tinyauth`은 `config.yaml` 이라는 단일 `yaml` 파일로 설정돼요. 이를 통해 로그인 방식, 보안, 데이터베이스 등 `tinyauth`를 운영하는데 필요한 대부분의 설정이 이루어져요. 설정 파일은 다음과 같은 주요 섹션들로 구성되어 있어요.

```yaml
# config.yaml
app:                  # 애플리케이션 설정
database:             # 데이터베이스 설정
auth:                 # 기본 인증 방식 설정
identity_providers:   # 타사 인증 방식 설정
smtp:                 # SMTP 이메일 설정
clients:              # 인증 클라이언트 설정
users:                # 사용자 설정
terms:                # 이용 약관 설정
cleanup:              # 데이터 정리 설정
scheduler:            # 작업 스케줄러 설정
```

작성한 `config.yaml`을 도커와 함께 사용하려는 경우 다음과 같이 사용할 수 있어요.

```bash
docker run \
  -p 8080:8080 \
  -v ./config.yaml:/opt/config.yaml \
  ghcr.io/tinyrack/tinyauth
```

## 최소 요구 설정

`tinyauth`을 사용하려면 최소한 다음의 설정을 구성해야 해요.

```yaml
# config.yaml
app:
  host: "https://내_도메인.com"
  cookie_secret: "아주_중요한_비밀_키"
```

- `host`: `tinyauth`에 접속할 때 사용할 URL을 지정해요. 공개된 서비스인 경우 보안을 위해 리버스 프록시와 `https` 프로토콜을 사용할 것을 강력히 권장드려요.
- `cookie_secret`: 로그인된 사용자의 세션 쿠키를 암호화하는 데 사용되는 비밀 키예요. 최소 **16자 이상**이어야 하며, `openssl rand -hex 32` 명령어를 통해 안전하게 생성할 수 있어요.
