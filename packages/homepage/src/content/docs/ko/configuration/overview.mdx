Tinyauth는 인증 서버의 모든 측면을 사용자 지정할 수 있는 YAML 기반 설정 시스템을 사용합니다.

## 설정 파일 위치

기본적으로 Tinyauth는 다음 위치에서 설정을 찾습니다:

- `packages/backend/config.yaml` (개발 환경)
- `/opt/config.yaml` (프로덕션 환경)

`CONFIG_PATH` 환경 변수로 재정의할 수 있습니다:

```bash
CONFIG_PATH=/path/to/config.yaml pnpm start
```

## 설정 구조

설정 파일은 다음 섹션으로 구성됩니다:

| 섹션 | 설명 |
|------|------|
| `app` | 애플리케이션 설정 (호스트, 포트, 테마, JWT 설정) |
| `database` | 데이터베이스 연결 설정 |
| `smtp` | 이메일 서버 설정 |
| `basic_authentication_methods` | 비밀번호 및 패스키 인증 설정 |
| `oauth_authentication_methods` | 소셜 로그인 프로바이더 (Google, GitHub, Apple) |
| `providers` | OAuth 클라이언트 애플리케이션 |
| `users` | 사전 설정된 사용자 계정 |
| `terms` | 이용약관 설정 |
| `account_deletion` | 계정 삭제 설정 |

## 환경 변수 보간

환경 변수를 참조하려면 `!env` 태그를 사용합니다:

```yaml
app:
  cookie_secret: !env COOKIE_SECRET

database:
  type: postgres
  password: !env DB_PASSWORD

smtp:
  password: !env SMTP_PASSWORD
```

## 최소 설정 예제

```yaml
app:
  host: http://localhost:8080
  port: 8080
  cookie_secret: !env COOKIE_SECRET

database:
  type: sqlite
  path: ./data/auth.db

basic_authentication_methods:
  password:
    enabled: true
```

## 전체 설정 예제

```yaml
app:
  name: My Auth Server
  host: https://auth.example.com
  port: 8080
  cookie_secret: !env COOKIE_SECRET
  jwt_access_token_ttl: 3600
  jwt_refresh_token_ttl: 2592000
  jwt_key_rotation_enabled: true
  jwt_key_rotation_days: 30
  supported_languages:
    - en
    - ko
    - ja
  default_language: auto
  light_theme: light
  dark_theme: dark
  theme_mode: system

database:
  type: postgres
  host: localhost
  port: 5432
  user: auth_user
  password: !env DB_PASSWORD
  name: tinyauth

smtp:
  host: smtp.example.com
  port: 587
  secure: true
  user: noreply@example.com
  password: !env SMTP_PASSWORD
  from: noreply@example.com

basic_authentication_methods:
  password:
    enabled: true
    email_verification: true
    totp:
      enabled: true
      issuer: My App
  passkey:
    enabled: true

oauth_authentication_methods:
  - type: google
    id: google
    enabled: true
    client_id: !env GOOGLE_CLIENT_ID
    client_secret: !env GOOGLE_CLIENT_SECRET

providers:
  - id: my-app
    name: My Application
    client_id: my-app-client-id
    client_secret: !env MY_APP_CLIENT_SECRET
    redirect_uris:
      - http://localhost:3000/callback
    response_types:
      - code
    grant_types:
      - authorization_code
      - refresh_token
    scope: openid profile email

account_deletion:
  enabled: true
  retention_period: 30d
```
