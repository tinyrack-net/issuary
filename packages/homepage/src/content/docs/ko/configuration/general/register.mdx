`tinyauth`는 기본적으로 화이트리스트 보안 정책을 가져요. 관리자가 허용한 이메일 패턴이 없으면 새로운 사용자는 스스로 가입할 수 없어요. 그래서 운영 대상에 맞게 `registration.allowed_email_patterns`를 먼저 정해야 해요. 계정 삭제 기능은 `account_deletion`에서 별도로 제어해요.

```yaml
# config.yaml
registration:
  allowed_email_patterns:
    - '*'

account_deletion:
  enabled: true
  retention: 30d
```

- `registration.allowed_email_patterns`: 등록을 허용할 이메일 패턴 목록이에요. `*`, `*@domain.com`, `user@example.com` 같은 값을 사용할 수 있어요. 빈 배열이면 자체 회원가입이 비활성화돼요.
- `account_deletion.enabled`: 사용자의 직접 탈퇴 기능을 허용할지 여부예요.
- `account_deletion.retention`: 탈퇴 요청 후 실제 영구 삭제까지의 유예 기간이에요.

---

## 예시

`tinyauth.net`, `tinyrack.net` 이메일을 가진 사용자의 가입을 허용하고, 사용자가 자신의 계정을 삭제할 수 있도록 설정하려면 다음과 같이 구성할 수 있어요.

```yaml
# config.yaml
registration:
  allowed_email_patterns:
    - '*@tinyauth.net'
    - '*@tinyrack.net'

account_deletion:
  enabled: true
  retention: 30d
```

모든 이메일 도메인에서의 가입을 허용하고 회원 탈퇴 기능을 비활성화 하려면 다음과 같이 구성할 수 있어요.

```yaml
# config.yaml
registration:
  allowed_email_patterns:
    - '*'

account_deletion:
  enabled: false
```
