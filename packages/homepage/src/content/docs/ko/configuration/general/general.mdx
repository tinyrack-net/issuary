`tinyauth`는 가급적 관리자의 수동 설정 없이도 원활하게 작동하도록 설계되었지만, 프로덕션으로 사용하려면 일부 항목은 명시적인 설정이 필요할 수 있어요. 설정 예시는 다음과 같아요.

```yaml
# config.yaml
app:
  host: ${APP_HOST:-http://localhost:8080}
  port: ${PORT:-8080}
  cookie_secret: ${COOKIE_SECRET}
```

- `host`: `tinyauth`에 접속에 사용할 기본 URL을 지정해요. 이는 사용중인 리버스 프록시 설정과 일치해야 하며, 공개된 서비스인 경우 `https` 프로토콜을 사용하는 것이 중요해요. `http` 프로토콜은 일부 기능(패스키)에 제한이 있을 수 있어요.
- `port`: `tinyauth` 서버가 수신 대기할 포트를 지정해요.
- `cookie_secret`: 쿠키를 암호화하는데 사용하는 32 바이트 비밀키를 지정해요.
`tinyauth`는 암호화된 `HTTP Only` 쿠키 방식으로 무상태 세션을 구현해요. 이 값을 중간에 변경하면 기존의 모든 세션이 무효화돼요.

:::note
`cookie_secret`은 `openssl rand -hex 32` 명령어로 안전한 값을 생성할 수 있어요.
:::

## 예시

`tinyauth`를 `https://auth.tinyrack.net` 도메인에서 운영한다면 다음과 같이 구성할 수 있어요.

```yaml
# config.yaml
app:
  host: https://auth.tinyrack.net
  port: 8080
  cookie_secret: 978aec42d5347fbbd6459948c558e8f5b9d0ee244bce983910a01aaf42692513
```
