title: 이메일 인증

---

이메일 인증은 비밀번호 로그인 기능을 사용할 때 이메일을 통한 추가 인증 절차를 요구하는 기능이에요.
다음의 옵션을 통해 이 기능을 활성화 할 수 있어요.

```yaml
auth:
  password:
    enabled: true
    email_verification: true
smtp:
  host: smtp.example.com
  port: 465
  secure: true
  user: $SMTP_USER
  password: $SMTP_PASSWORD
  from: "TinyAuth <noreply@tinyauth.com>"
```

이 기능을 활성화면 사용자는 다음의 기능을 사용할 수 있게 돼요.

- 사용자 회원가입 시 인증 코드 전송
- 사용자 비밀번호 초기화 링크 전송
