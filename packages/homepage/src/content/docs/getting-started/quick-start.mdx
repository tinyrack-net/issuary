This guide will help you get Tinyrack Auth running quickly for development purposes.

## Prerequisites

- Node.js 20.x or later
- pnpm 9.x or later

## 1. Clone and Install

```bash
git clone https://github.com/tinyrack/auth.git
cd auth
pnpm install
```

## 2. Create Configuration

Create `packages/backend/config.yaml` with minimal configuration:

```yaml
app:
  host: http://localhost:8080
  port: 8080
  cookie_secret: your-super-secret-key-min-16-chars

database:
  type: sqlite
  path: ./data/auth.db

basic_authentication_methods:
  password:
    enabled: true
    email_verification: false
```

## 3. Start the Server

```bash
pnpm dev
```

Your OIDC provider is now running at `http://localhost:8080`.

## 4. Test the Setup

Visit the following URLs to verify:

- **Login Page**: http://localhost:8080
- **OpenID Configuration**: http://localhost:8080/.well-known/openid-configuration
- **JWKS**: http://localhost:8080/.well-known/jwks.json

## 5. Register a Test User

Navigate to `http://localhost:8080` and click "Sign Up" to create your first user.
