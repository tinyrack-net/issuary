This guide will walk you through setting up Tinyauth for development or production use.

## Prerequisites

Before you begin, make sure you have the following installed:

- **Node.js** 20.x or later
- **pnpm** 9.x or later (recommended package manager)
- **Git** for cloning the repository

## Quick Start

### 1. Clone the Repository

```bash
git clone https://github.com/tinyrack/auth.git
cd auth
```

### 2. Install Dependencies

```bash
pnpm install
```

### 3. Configure the Application

Create a configuration file at `packages/backend/config.yaml`:

```yaml
app:
  host: 0.0.0.0
  port: 8080
  base_url: http://localhost:8080
  jwt_key_rotation_enabled: true
  jwt_key_rotation_days: 30

database:
  type: sqlite
  path: ./data/auth.db

smtp:
  host: smtp.example.com
  port: 587
  user: your-email@example.com
  password: !env SMTP_PASSWORD

basic_authentication_methods:
  password:
    enabled: true
    email_verification: false
    totp:
      enabled: true
  passkey:
    enabled: true

users:
  - id: admin-user-id
    email: admin@example.com
    password: !env ADMIN_PASSWORD
```

### 4. Start Development Server

```bash
pnpm dev
```

This will start:
- Backend server at `http://localhost:8080`
- Frontend dev server at `http://localhost:8081`

## Environment Variables

Create a `.env` file in the root directory:

```bash
# SMTP password for email sending
SMTP_PASSWORD=your-smtp-password

# Admin user password
ADMIN_PASSWORD=your-secure-admin-password
```

## Database Options

Tinyauth supports multiple database backends:

### SQLite (Default)

```yaml
database:
  type: sqlite
  path: ./data/auth.db
```

### PostgreSQL

```yaml
database:
  type: postgres
  host: localhost
  port: 5432
  user: postgres
  password: !env DB_PASSWORD
  database: tinyauth
```

### In-Memory (Testing)

```yaml
database:
  type: memory
```

## Building for Production

```bash
# Build all packages
pnpm build

# Start production server
cd packages/backend
pnpm serve
```
