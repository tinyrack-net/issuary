`tinyauth`는 프론트엔드에서 다국어를 기본적으로 지원해요. 다음은 언어 설정에 관한 구성 예시예요.

```yaml
i18n:
  supported_languages:
    - en
    - ko
    - ja
  default_language: auto
  fallback_language: ko
```

- `supported_languages`: 프론트엔드에서 지원할 언어 목록이에요. 언어 코드는 `ISO 639-1` 규격을 사용해요. 예를 들어, 영어는 `en`, 한국어는 `ko`, 일본어는 `ja`예요.
- `default_language`: 브라우저에서 사용자에게 보여줄 언어의 기본값을 지정해요. 자동으로 브라우저 언어를 감지하려면 `auto`로 설정하세요. 특정 언어 코드를 지정하면 해당 언어가 항상 기본 언어로 먼저 표시돼요.
- `fallback_language`: `default_language`가 `auto`이면서, 사용자의 브라우저 언어가 `supported_languages`에 없을 경우 사용할 대체 언어예요. 기본값은 `en`(영어)이에요.
